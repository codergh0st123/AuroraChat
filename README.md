# AuroraChat

**AuroraChat** — плагин чата для серверов Paper Minecraft 1.21.4. Проект собран на Gradle, использует Java 21 и не содержит встроенных сторонних библиотек. JAR-файл можно сразу поместить в папку `plugins` сервера.

## Установка

Скопируйте `AuroraChat-1.0.0.jar` из каталога `build/libs` в папку `plugins` сервера Paper 1.21.4 и перезапустите сервер. После первого запуска будет создан файл `plugins/AuroraChat/config.yml` с заданной конфигурацией.

## Команды и права

| Команда | Назначение | Право |
|---|---|---|
| `/pm <игрок> <сообщение>` | Отправить личное сообщение. Также доступны `msg`, `tell` и `w`. | `aurorachat.pm` |
| `/spy <on|off>` | Включить или выключить просмотр личных сообщений. | `aurorachat.spy` |
| `/pmsound` | Открыть меню выбора звука входящих личных сообщений. | `aurorachat.sound` |
| `/aurorachat reload` | Перезагрузить конфигурацию плагина. Также доступен алиас `/ac reload`. | `aurorachat.reload` |

Глобальное сообщение начинается с символа, заданного параметром `globalChatPrefix`; при исходной конфигурации это `!`. Сообщение без этого символа отправляется в локальный чат в пределах `localChatRadius` блоков.

Цвета, hex-форматы, градиенты и сторонние плейсхолдеры обрабатываются как в `config.yml`, так и непосредственно в тексте, отправленном игроком в глобальный чат, локальный чат или через `/pm`. Поддерживаются `&a`, `&#12AB34`, `&x&1&2&A&B&3&4`, тег одного hex-цвета `<#12AB34>` и градиент `<gradient:#FF0000:#00FF00>Текст</gradient>`. Также допускается запись градиента через `&#`, например `<gradient:&#FF0000:&#00FF00>Текст</gradient>`.

## PlaceholderAPI

Установите [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) и нужные расширения на сервер. После этого сторонние плейсхолдеры можно писать непосредственно в любой строке раздела `messages` файла `config.yml`; AuroraChat обработает их перед цветами и перед выводом сообщения. Например, в `global_format` можно использовать строку `"&cɢ &f%player_name% &7[%vault_rank%]&f: {сообщение}"`.

Плейсхолдеры получают контекст игрока, которому выводится строка. Поэтому в личных сообщениях `%player_name%` подставит имя отправителя в сообщении для отправителя и имя получателя в сообщении для получателя. Плейсхолдеры из текста игрока также обрабатываются с его контекстом: например, отправленное сообщение `&a%player_name%` будет окрашено и подставит имя автора сообщения.

## LuckPerms

Если `useLuckPermsPrefix: true`, AuroraChat получает префикс из кэша LuckPerms и подставляет его вместо `%tab_tabprefix%` в форматах чата. При отсутствии LuckPerms плагин продолжает работать: указанный плейсхолдер будет заменён пустой строкой.

## Сборка из исходного кода

В корне проекта выполните команду `./gradlew clean build`. Готовый файл будет расположен по пути `build/libs/AuroraChat-1.0.0.jar`.

## Проверка качества

Перед передачей выполнена чистая сборка `./gradlew clean build --no-daemon --warning-mode all`. Компиляция завершена успешно без ошибок и предупреждений. Для исключения утечек временное состояние режима шпиона очищается при выходе игрока, а настройки звука сохраняются только по UUID игрока в отдельный файл `preferences.yml`.
